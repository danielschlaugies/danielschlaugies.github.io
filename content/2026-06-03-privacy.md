### How this website is hosted and delivered

This website is a static website hosted with GitHub Pages.

I use Cloudflare as a content delivery network, DNS provider, and security service.
This means your request reaches Cloudflare first.
Cloudflare then helps deliver the website and forwards requests to GitHub Pages.

The following providers process technical data to deliver and secure this website:

- GitHub B.V., GitHub, Inc., and their group companies.
- Cloudflare, Inc. and its group companies.

I use these providers so that the website loads reliably, stays available, and remains protected against abuse and attacks.
